# Changelog

**Audience:** Users.

## 1.0.1

- Fixed Windows release checks and updated the build actions for Node.js 24.

## 1.0.0

- Windows installer and portable app with a bundled runtime.
- Editable objects, rooms, routes and vegetation, with textures and example scenes.
- Project saving, OBJ export, and SWBF2 asset and scene export.
- Direct world-folder export, reusable object copies, and optional AI planning.

Detailed implementation history is kept in the [development log](docs/reference/development-history.md) for contributors and coding agents.
